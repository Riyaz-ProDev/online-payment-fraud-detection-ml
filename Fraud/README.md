# Online Payment Fraud Detection System

## Overview
A Machine Learning based fraud detection application developed using Django, Python and MySQL.

The system detects fraudulent online transactions using balanced machine learning algorithms.

## Technologies Used

Frontend:
- HTML
- CSS
- Bootstrap

Backend:
- Django
- Python

Database:
- MySQL

Machine Learning:
- Random Forest
- Logistic Regression
- Naive Bayes
- SMOTE


## ML Workflow

1. Data Collection
2. Data Preprocessing
3. Handling Imbalanced Data using SMOTE
4. Model Training
5. Model Evaluation
6. Fraud Prediction


## Features

- User Login
- Transaction Prediction
- Fraud Detection Dashboard
- Prediction History
- Model Accuracy Comparison
